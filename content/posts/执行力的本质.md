拖延症恐怕是个比感冒还流行的疾病，我曾深受其害。对于解决办法，我内求不得，于是就向外求解，可令我沮丧的是，相当一部分受人推崇的知乎答主、B 站博主以及 YouTuber，他们讲得头头是道，却完全没有从根本上解答该问题，我对此感到失望，于是干脆秉承着「第一性原理」，自行分析。

解决一个问题的前提是能够清晰描述该问题，因此要想解决拖延症，就应该从更本质的层面对它进行描述。

我们之所以拖延，是因为执行力不足，那么执行力如何提升呢？相关的方法论五花八门，其中不乏有中学生打鸡血式的情绪激励，由于这太过低级，本文就不浪费笔墨展开了。还有一部分说法更吸人眼球：“你拖延的原因并非忌惮失败，而是害怕成功”，要我说，这是一句极浅薄的话，它除了给人以耳目一新的错觉以外，根本于事无补。

接下来我们从执行力的定义开始：

> 执行力，是一个人持续让现实状态向目标状态发生变化的能力。

糊涂地将执行力形容成一个性格特质，显然是偷懒的做法。我们拿思辨做大炮，将执行力轰个粉碎，便能发现它并非一个单纯的**特质**，而是由若干个更为原子的能力所表现出的**现象**。

执行力差是由一系列问题累积而成的，以下表为例：

| **表面现象**       | **真正可能出问题的环节** |
| ------------------ | ------------------------ |
| 一直不开始         | 启动能力                 |
| 不知道先干什么     | 任务拆解                 |
| 做两分钟就去刷手机 | 注意力控制               |
| 遇到困难马上停     | 阻力处理                 |
| 做了很多但没结果   | 优先级/方向的制定        |
| 总想等准备充分     | 不确定性耐受力太低       |
| 三分钟热度         | 持续机制没能建立起来     |

我为执行力 / 行动力粗略的总结出了 10 大要素：

1. **启动能力**：能否启动任务，而不是顾左右而言他
2. **目标澄清和任务拆解能力**：明确最终的产出，并拆解任务为明确的原子
3. **注意力控制**：不会心猿意马，能够将注意力集中在当前任务上
4. **阻力控制**：降低影响自己执行任务的阻力，例如把手机拿开、关闭视频网站等
5. **优先级控制**：知所先后，拿得准主要矛盾，不在细枝末节上耗费时间
6. **不确定性耐受度**：不追求无谓的完美和万事俱备，先完成后完美
7. **持续机制**：不会做了一会就不做了
8. **重启能力**：专注一次后还能接上第二次
9. **反馈与纠偏能力**：判断当前行动是否有效，随机应变，避免谬以千里
10. **状态管理能力**：保持充足的睡眠，进而保护自己的精力和身体状态

我想这或许可以作为一个简易的自查表，只要我们能逐一击破，并实时反省、坚持实践，那么拖延症就不再是绝症。
