# Categories 栏目

## 目标

在导航的搜索右侧提供 Categories／专栏入口。作者只需在文章 Front Matter 填写 `categories`，即可在英文和中文入口按大类浏览文章；`tags` 继续用于细节标签。

## 验收条件

- `/categories/` 与 `/zh/categories/` 均可访问，导航位置在 Search／搜索右侧。
- 手机窄屏上三个导航入口始终完整可见，切换到 Articles／文章后也不会裁掉 Categories／专栏。
- 未填写 `categories` 时，两个入口显示各自语言的空状态。
- 给规范语言文章填写一个新分类后，两个入口都出现该分类、正确的文章数和可展开的文章链接。
- 本地 `hugo server` 中修改现有文章的 `categories` 并保存后，刷新两个入口即可看到新归属，无需重启服务。
- 分类卡片可用鼠标和键盘展开；文章链接指向规范语言文章。
- 展开后每篇文章显示标题、两行正文摘要、发布日期及 Tags；栏目标题与首篇文章间的分隔线至少是文章之间分隔线的两倍粗细，英文文章计数无多余引号。
- 原有 Tags、首页、Archive 和搜索索引不因分类而改变。

## 边界

Hugo 自动生成规范语言的原生分类 term 页；中文入口的总览卡片直接展开文章列表，不依赖中文 term 页。栏目内容由文章 Front Matter 决定。
