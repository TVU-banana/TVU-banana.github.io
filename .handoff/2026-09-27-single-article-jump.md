# 2026-09-27：合并文章顶部与末尾跳转按钮

## 目标与决策

- 用户要求把前一轮的两个文章跳转按钮合并为一个，箭头随真实滚动位置及时变化。
- 文章页接近顶部（`scrollY <= 80` 且仍能继续滚动）时，唯一按钮向下并跳到 `#article-end`；离开顶部后向上并跳到 `#top`。滚动、窗口尺寸变化及页面载入都会刷新状态，不依赖按钮上一次被点击的方向。
- 页面无需滚动时隐藏该按钮；非文章页继续使用原有超过 800px 后出现的返回顶部按钮。保留站点覆盖层的圆形样式与居中箭头，不修改主题子模块。

## 修改文件

- `layouts/partials/footer.html`：文章页只输出一个 `article-jump-link`，以实际滚动位置同步箭头方向、目标、辅助技术标签和提示；其他页面保留原 `top-link`。
- `assets/css/extended/custom.css`：移除第二按钮的偏移样式，单按钮居中并按状态旋转箭头。
- `docs/architecture.md`：更新当前渲染契约。
- 本记录与 `.handoff/latest.md`：更新当前交接入口。
- 前一轮添加的 `layouts/_default/single.html` 末尾锚点仍由单按钮使用，本轮未再改动。

## 验证证据

- Hugo `0.166.0` 本地构建成功；英文文章仅输出一个文章跳转按钮和末尾锚点，中文归档继续输出普通返回顶部按钮。
- 本地 Hugo Server 浏览器检查：文章顶部为向下箭头；手动下滚后变向上；点击向上后回到 `scrollY=0`、恢复向下；点击向下后到页面底部并变向上；在带 `#article-end` 的页面刷新后，箭头随实际恢复的滚动位置变向上。
- 本轮修改文件的 `git diff --check` 通过。
