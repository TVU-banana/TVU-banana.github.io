# 2026-09-27：文章页顶部与末尾跳转按钮

## 目标与决策

- 用户要求优化文章自动滚动到顶部和末尾的按钮，保留现有圆形外观并改善居中。
- 检查当前工作区发现只有 PaperMod 的返回顶部按钮；在站点覆盖层补充文章末尾按钮，两个按钮沿同一右侧轴线排列，SVG 在圆形按钮内水平、垂直居中。
- 不修改主题子模块；已有文章和子模块工作区改动保持原样。

## 修改文件

- `layouts/_default/single.html`：文章 footer 增加 `article-end` 锚点。
- `layouts/partials/footer.html`：仅 `posts` 文章页输出跳到末尾按钮，保留原返回顶部行为。
- `assets/css/extended/custom.css`：两个箭头统一用 grid 居中，末尾按钮位于返回顶部按钮上方。
- `docs/architecture.md`：记录当前文章页跳转控件的模板与样式来源。
- 本记录与 `.handoff/latest.md`：记录本轮验证和边界。

## 验证证据

- Hugo `0.166.0` 本地构建成功；生成的英文文章包含页尾锚点和两个按钮，首页与中文归档/分类页没有文章末尾按钮。
- 本地 Hugo Server 的英文长文章浏览器检查：两个 42×42px 按钮同一 x 坐标，SVG 中心相对按钮中心的 x/y 偏差均为 0；末尾按钮滚动到页面最底部，回顶按钮滚动到 0 且清除 hash。
- `git diff --check` 对本轮实现文件通过。
